개인정보처리방침

시행일: 2026년 11월 16일

1. 수집하는 정보

구글 로그인 시 계정의 이메일 주소와 이름(기본 프로필)을 받아, 로그인한 계정을 구분하고 화면에 표시하는 데에만 사용합니다.

2. 구글 드라이브 접근

이 앱은 Google Drive의 drive.file 권한만 요청합니다. 이 권한으로는 이 앱이 직접 만든 파일(스프레드시트 "학급관리 데이터", 폴더 "학급관리_파일" 및 그 안의 파일, 내보내기로 만든 스프레드시트)만 읽고 쓸 수 있으며, 드라이브의 다른 파일에는 접근할 수 없습니다.

3. 저장 위치와 보관

사용자가 입력한 학급 정보(학생 명렬표, 기록, 성적, 자리, 역할 등)는 사용자 본인의 구글 드라이브에만 저장됩니다. 앱 운영자는 별도의 서버나 데이터베이스를 운영하지 않으며, 사용자의 데이터를 수집·열람·보관하지 않습니다. 로그인 정보(접근 토큰)는 브라우저 메모리에만 잠시 보관되고 약 1시간 뒤 만료됩니다.

4. 제3자 제공

사용자의 정보를 제3자에게 제공하거나 판매하지 않습니다. 구글 API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

5. 삭제

구글 드라이브에서 "학급관리 데이터" 스프레드시트와 "학급관리_파일" 폴더를 삭제하면 모든 데이터가 삭제됩니다. 앱의 접근 권한은 구글 계정 설정의 "타사 앱 및 서비스"(myaccount.google.com/connections)에서 언제든지 해제할 수 있습니다.

6. 학생 정보 관련 안내

학생 정보는 교사 본인의 구글 계정에 저장되므로, 소속 학교·교육청의 개인정보 보호 지침에 맞게 사용해 주세요.

7. 문의

구글 로그인 화면의 "개발자 정보"에 표시된 이메일로 문의해 주세요.
